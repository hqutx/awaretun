# Security policy

AwareTun is an experimental prototype, not a production VPN. Its current QUIC
configuration encrypts traffic but does not authenticate peer identities. Do
not use it on untrusted networks or route sensitive traffic through it. The
README describes additional limitations.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Once this project
is hosted on GitHub, use the repository's **Report a vulnerability** option to
send a private report. Include the affected version or commit, steps to
reproduce, and relevant device and Android version details. If private
vulnerability reporting is not enabled, ask a maintainer to establish a private
reporting channel before sharing details.

There are no supported release versions yet; security fixes will be handled on
the current development branch.
